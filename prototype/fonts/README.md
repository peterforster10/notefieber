# Schriften für den Prototyp

Inter (variabel, nur `latin`) und IBM Plex Mono (400, 500, nur `latin`) als woff2, kopiert aus den
npm-Paketen `@fontsource-variable/inter` und `@fontsource/ibm-plex-mono`, die auch der Web-Client nutzt.
Beide stehen unter der SIL Open Font License 1.1 (`LICENSE-Inter.txt`, `LICENSE-IBM-Plex-Mono.txt`).
Vom eigenen Server statt von Google Fonts, wie im Produkt (CLAUDE.md, Abschnitt 3).
